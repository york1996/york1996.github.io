04 平台专题

主流平台一次讲透，选一个跑通再复制

不同平台的门槛、资金、玩法差异很大。这里覆盖 Amazon / Shopee / TikTok Shop / Temu·SHEIN / eBay / Etsy / AliExpress / Lazada 等主流选项，并给出选型建议。

📊 平台一览（可交互对比）

先看整体，再深入到具体平台。5 维度打分：新手友好 / 起量速度 / 利润潜力 / 天花板 / 品牌价值。

💡 选型 5 步法：① 看资金 ② 看品 ③ 看时间 ④ 看能力 ⑤ 看目标。
不确定？用 5 道题的模式适配测试快速定位 →

🟠 Amazon 亚马逊（严肃卖家首选）

主要市场
美/欧/日/加/澳/中东

3–8 万

入驻准备

  • 中国公司营业执照（英文翻译件）+ 法人身份证/护照
  • 双币信用卡 Visa/Master（可绑万里汇/PingPong 虚拟卡）
  • 收款账户：ACCS 或第三方（PingPong/万里汇/Payoneer/Airwallex）
  • 公司邮箱 + 手机 + 3 个月内水电煤账单（KYC 二审用）
  • 类目审核资料（儿童 CPC / 化妆品 FDA / 电器 UL/FCC/CE）
KYC 二审：30–90 天做二审，需上传营业执照、法人证件、3 个月水电煤账单、银行/信用卡对账单、视频面审。抬头/地址/日期必须一致，材料不全直接封号。

FBA vs FBM

FBA（推荐）

✅ Prime 标、买家信任、代仓代发
❌ 仓储费高（尤其 Q4 + 长期库存）、周转慢就亏
每 3 个月清一次滞销品

FBM（自发货 / 海外仓）

✅ 无 FBA 费、灵活
❌ 无 Prime、时效差
用海外仓可打 Seller Fulfilled Prime（要求高）

亚马逊常见"死法"

  1. 二审失败 → 材料造假或抬头对不上
  2. 评论操纵 → 找测评被查
  3. 关联封号 → 多账号同 IP/同信用卡/同收款
  4. 侵权投诉 → 未查专利就上架
  5. 库存堵死资金 → 备货过量
  6. 跟卖 / 恶意攻击 → 未做品牌备案
  7. VAT/税务合规 → 欧洲不报 VAT 直接停售

🟠 Temu / SHEIN 全托管（工厂型玩家最快出海）

Temu（拼多多海外）

  • 主战场：US/EU/UK/JP/KR/MX/AU/CA 等 70+ 国
  • 主体：中国大陆公司 / 个体户
  • 模式：竞价供货（平台定价，卖家报价低者中标）
  • 结算：出货后按周或按批人民币直付
  • 入驻：seller.kuajingmaihuo.com

SHEIN

  • 服饰、家居垂直起家，现全品类
  • 两条路：卖家平台化 or 代工/全托管
  • 快反供应链：72h 打样、7–14 天量产
  • 结算周期比 Temu 长（60–90 天常见）
  • 供应链在广州番禺、佛山
全托管利润薄：净利率通常 5–15%，靠规模 + 周转 + 长尾单量取胜。没有工厂优势基本做不到。

聪明的用法

把全托管当"测品与清库存"渠道：

  1. 用 Temu / SHEIN 短时间验证海外真实需求
  2. 数据反过来指导你在亚马逊 / 独立站做品牌型精品
  3. 库存/尾货通过全托管清掉，不砸手里

🟠 其他平台（次选 or 特色）

eBay

市场：美/英/德/澳。老平台、增长慢、规则老旧。
优势品类：汽车零件、乐器、二手、工业品、玩具收藏。收款：Managed Payments，绑 Payoneer/万里汇。

AliExpress 速卖通

阿里系跨境 B2C，主战场：俄语区、西班牙、法国、巴西、中东、韩国。有普通模式 + Choice 半/全托管。适合新手 / 俄语区 / 义乌小商品。

Lazada

阿里系东南亚，与 Shopee 90% 重叠。竞争没 Shopee 卷但流量也小。建议 Shopee + Lazada 双开，同 SKU 铺。

Etsy

手工艺 / 复古 / 定制 / 数字商品 / 婚庆。高利润、买家审美好、无广告依赖。中国主体注册难，多数需海外身份 + Payoneer。

阿里国际站

B2B 批发。一单几千到几万美元。培育周期长（3–12 个月）。适合工厂/老外贸转型。入驻 ¥29800/年起。

Wish

已明显衰退，2022 后规则、结算、争议高。不建议新手入局。

Ozon（俄罗斯）

俄罗斯 GMV 第一。市场大、竞争相对少。缺点：卢布/汇兑复杂、俄语门槛、地缘波动。

Mercado Libre（拉美）

拉美第一，覆盖巴西、墨西哥、阿根廷、智利、哥伦比亚。巴西站最大也最复杂（葡语 + 高税制）。

Rakuten / Yahoo! Japan / Qoo10

日本市场。Rakuten 门槛高（月租 5–10 万日元）。Yahoo! Shopping 门槛低（免费入驻）。Qoo10 面向东北亚。

Coupang（韩国）

韩国头部，Rocket 物流类似 Amazon Prime。竞争激烈，需本地库存。

次要平台的正确用法：不建议把主战场放在这些平台（除非你有独特资源）。可以作为分销备用渠道、库存周转出口、特定小语种市场试水。
主战场永远优先跑通：亚马逊 / Shopee / TikTok Shop / 独立站 之一。
