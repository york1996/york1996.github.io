你的阶段建议

主体类型（选哪种）

个体工商户

最低门槛

门槛低、无注册资本、能开发票、能收 B 端收款。
缺点：不能出口退税、外币账户受限、部分平台不认。适合极小规模测试。

有限责任公司

推荐

绝大多数跨境卖家选择。可开外币账户、可申请进出口权、可开专票、可申请退税、股权融资灵活。

一人有限公司

注意

单一自然人股东，法律责任比个体大。注意"人格混同"风险，公私账务必须严格分开。

香港 / 海外公司

后期考虑

常用于收款和品牌形象。新手不必一开始就注册。年销售 100 万美元以上再考虑"内地公司 + 香港/BVI 公司"架构。

注册地怎么选

🏙️ 深圳（前海/龙华/宝安）

跨境电商第一城，政策友好、服务商密度最高。

🏙️ 杭州 / 宁波 / 义乌

外贸传统强，义乌小商品供应链无敌。

🏙️ 广州 / 东莞

3C、家居、服饰供应链。

🏙️ 厦门 / 福州

Shopee、Lazada 等东南亚平台服务商密集。

🏙️ 园区注册（如前海）

可享一定税收返还，但要求实缴、真实经营，慎选。

🏙️ 本地注册也可以

业务在线上，本地注册完全能跑。

需要准备的资料

  • 法人和股东身份证正反面
  • 法人、股东、监事的电子签名 U 盾或人脸识别（e窗通 / 一网通办 / 粤商通）
  • 注册地址证明（自有房产证 / 租赁合同 / 挂靠地址）
  • 3–5 个公司名候选（格式：行政区 + 字号 + 行业 + 有限公司）
  • 经营范围（见下）
  • 注册资本（认缴制，建议 50–100 万，注意 2024 年新法要求 5 年内实缴）

经营范围模板（跨境电商常用）

互联网销售（除销售需要许可的商品）；国内贸易代理；
进出口业务；货物进出口；技术进出口；
供应链管理服务；
服装服饰、日用百货、电子产品、家居用品、化妆品、
玩具、宠物用品、母婴用品的销售（涉及许可的除外）；
互联网信息服务（增值电信业务经营许可证除外）；
市场营销策划；企业管理咨询；平面设计。
涉及化妆品/食品/医疗器械/图书/危险品/酒等需前置或后置许可。

1

用于收美元、欧元

7
签约第三方收款

PingPong / 连连 / Airwallex / 万里汇 / Payoneer

8
社保开户

哪怕只有一个法人，很多城市要求

一个人怎么注册（深圳示例）

  1. 微信搜"深圳市场监督管理局" / "深圳 e 窗通" → 实名认证 → 网上申请
  2. 起名 → 选行政区 → 填地址（自有/挂靠）→ 填经营范围 → 填股东法人监事
  3. 全体人员用手机 APP 电子签名（深 i 企 / 粤商通）
  4. 审核通过（1–3 个工作日）→ 领电子/纸质营业执照
  5. 微信预约刻章点刻章（半天）
  6. 银行网点预约开对公户（1–2 周）
  7. 税务局报到 → 领发票 → 完成

4 类法律法规（务必知道）

  • 《对外贸易法》《海关法》《进出口商品检验法》：出口备案、报关、法检品类要求
  • 《跨境电子商务零售出口商品监管办法》：明确 9610/9710/9810 等监管代码
  • 《税收征收管理法》/ 增值税暂行条例：出口"免抵退"或"免税"政策
  • 《外汇管理条例》：外汇结汇需申报，个人年结汇 5 万美元不能拆分给公司业务
  • 反洗钱/反恐融资：大额、频繁、拆分收款都会被银行/PSP 风控
  • 美国：FDA / FCC / UL / CPSC / 加州 Prop 65 / CPSIA（儿童）；销售税各州不同；2025 起对中国商品取消 800 美元 De Minimis 免税
  • 欧盟：CE / RoHS / REACH / EN71；VAT 强制；IOSS（≤ €150）；GPSR（2024.12 起强制欧代信息）；GDPR；DSA
  • 英国：UKCA / VAT / UK Responsible Person
  • 日本：PSE（电器）/ METI 备案（无线）/ 消费税 JCT（2023 起）
  • 澳洲：RCM / GST / ACL
  • 中东（沙特/阿联酋）：SASO/SABER / G-Mark / VAT
  • 亚马逊：一品一账号、二审、真实性审核、评论政策、品牌备案 R 商标
  • Shopee/Lazada：一人多店铺规则、SIP 计划、本地公司要求
  • TikTok Shop：内容+电商双合规、直播资质、小店类目准入
  • Etsy：手工/复古/工艺品资质证明
  • PayPal/Stripe：账户资金冻结、180 天备付金政策
  • 商标（最重要）：在目标市场国注册（美国 USPTO / 欧盟 EUIPO / 日本 JPO）。没有目标国商标 = 随时被下架/被抢注
  • 专利：小心侵权国外专利（尤其亚马逊老品类），APEX 会自动下架侵权 Listing
  • 版权：产品图、包装设计、Logo 都受版权保护

海关监管代码（新手只需分清）

代码名称场景是否退税
9610B2C 直购出口一件小包直发消费者（低值）❌ 通常免税不退税
9710B2B 直接出口平台/海外仓 B2B 出口✅
9810海外仓出口中国 → 海外仓一次性大批量✅
1210保税跨境电商保税区备货再发（进口为主）–
0110一般贸易传统大宗出口，最完整报关✅

新手要记：亚马逊 FBA 一般走 9810 或 0110；小包直发走 9610；退税需要报关单 + 增值税专用发票。

税务：出口退税与常见坑

  • 出口退税：一般纳税人 + 进项专票 + 报关单齐全，可退 13% 或 9%（视商品）。跨境重要利润来源。
  • 免税模式：小规模或无票采购走出口免税（不退不缴）。
  • "买单出口"（灰色）：新手强烈不建议。不能退税、不能合规结汇、稽查风险大。
  • 企业所得税：一般 25%（小型微利有优惠：≤ 300 万部分 5%）
  • 个人所得税：分红 20%；工资走综合所得。

外汇合规（3 条主流路径）

1️⃣ 对公美元直接结汇

最正规。平台放款 → 银行外币户 → 结汇。需银行申报交易性质。

2️⃣ 第三方跨境收款（新手最常用）

PingPong / 连连 / Airwallex / 万里汇 / Payoneer。费率 0.3–0.7%、有牌照、合规。

3️⃣ 香港/离岸公司 + 全球银行账户

适合有规模、需多币种/全球采购的团队。新手不必。

红线（千万别踩）：
❌ 用亲戚朋友银行卡拆分收款（反洗钱）
❌ 用境外第三方（PayPal 私人号）长期收公司货款
❌ 不申报直接换汇
