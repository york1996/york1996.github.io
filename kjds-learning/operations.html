1. 选品 —— 60% 的胜负手

选品第一性原理
  • 有需求：市场在搜、有人在买、类目在涨
  • 有差异：不完全同质化，有你能加的一层"改良点"
  • 有毛利：售价 ÷ 到岸成本 ≥ 3 倍
  • 可运输：小、轻、不易碎、不带电/磁/液
  • 不违规：不涉及 IP、不属于违禁类
  • 有复购/高客单：一次性 + 低客单 = 广告费永远打不平

新手黄金公式

体积小 × 单价 15–50 USD × 目标毛利 ≥ 40% × 无认证门槛 × 无侵权

选品的 5 种思路

数据反推法（新手推荐）

用工具看类目 BSR、增速、评价数、评分。找"评价数 < 500、月销 > 500、竞争度中等"的坑位。

工具：Helium 10 Jungle Scout 卖家精灵 BigSpy Minea

关键词反推法

从"搜索需求"倒推。找"搜索量 > 1000、竞争度低、商业意图明显"的长尾词。

例：cat scratcher for large cats 比 cat toy 好定位得多。

竞品跟卖 + 微创新

找已经跑起来的品，做"改良版"。差异化维度：材质升级 / 颜色尺寸新增 / 组合销售 / 包装升级 / 说明书视频完善。

⚠️ 不要 100% 抄袭，尤其外观和文案
供应链倒推法

你有工厂/供应商资源，反过来找"这个货在海外哪个平台好卖"。适合工厂型卖家。

社媒 / 内容倒推法

刷 TikTok、Instagram Reels、YouTube Shorts、Pinterest，看"最近突然火"的产品。

工具：Kalodata Fastmoss Shoplus Pipiads

评估打分 & 红线

✅ 12 项打分卡

给每个候选品打分，总分 ≥ 45 再考虑上架。搜索量 / 竞争度 / 售价倍率 / 重量体积 / 危险品 / 认证 / 知产 / 可视化 / 复购 / 供应稳定 / 季节 / 你愿意用它。

→ 打开选品打分器
❌ 必须避开的红线
  • 侵权品：迪士尼/漫威/明星肖像/大牌商标
  • 危险品：锂电、液体、气体、香水、磁铁
  • 医疗类：口罩、体温计、隐形眼镜
  • 食品/保健品：多国需注册
  • 管制品：武器、激光笔、电子烟

可复用的选品工作流

周一
拉候选品

Helium10 / BigSpy / TikTok 找 20 个候选

周二
打分

逐个填 12 项打分卡，筛出 5 个

周三
查风险

专利/商标/认证查一遍，筛出 3 个

周四
询价

1688 找 3 家供应商，算到岸成本 + 毛利

周五
定测品

定 1 个测试品，下 50–100 件小单

2. 供应链与采购

货源渠道

渠道场景优点缺点
1688起步首选品类全、门槛低、多支持一件代发部分是二级贸易商
义乌购 / 义乌小商品城小商品 / 饰品 / 家居价格极低、SKU 极多品质参差

产业带品类深耕深圳 3C / 东莞玩具 / 广州服饰 / 义乌小百货需要跑一趟

选供应商的 8 条硬标准

1. 能开发票

增值税专用发票，用于退税

2. 能小批量试单

100 件以内先做样

3. 有验厂能力

可预约现场或视频看厂

4. 产品有质检

尤其电器/儿童/化妆品

5. 响应速度快

1688 消息 4 小时内回复

6. 有跨境经验

聊清 FBA / 海外仓要求

7. 可定制包装

未来一定用到 OEM

8. 不霸王条款

阶梯打款 + 品质纠纷条款

库存与备货节奏：新品首单 50–200 件 测试。补货公式：
安全库存 = 日均销量 × 补货周期（含头程） × 1.3 缓冲系数
60/30/10 法则：60% 海运常规 / 30% 空运补货 / 10% 快递应急。

3. 物流与仓储

三种基本形态

直邮小包

邮政小包 / 专线小包 / 国际快递（DHL、UPS、FedEx）。慢但便宜，适合起步。

海外仓 / 平台仓

FBA / SLS / LGS / FBT。快、体验好，独立站也能用。有仓储费。

全托管 / 平台代发

货送到平台国内仓（Temu 广州仓、SHEIN 佛山仓），后续不用管。

双清包税 vs 关税自理

DDP · 双清包税

货代帮你搞定出口报关 + 目的国清关 + 关税/VAT。适合中小卖家，省心但灰色成本高。

DDU / DAP · 关税自理

只到目的港，你自己找当地清关行报关。适合大卖家 + 已注册 VAT + 有 EORI。

常见物流坑：头程不认 FBA 贴标要求 / 旺季爆仓 / 敏感货被扣 / VAT 未申报货被扣 / 仓储费失控（长期库存超 271 天翻倍）/ 货代跑路。

4. 支付、收款与财务

钱的三种通道

① 消费者的钱 → 平台/独立站
② 平台/独立站 → 你的收款账户（多币种）
③ 你的收款账户 → 结汇 → 公司人民币账户 → 报税/分红/采购

第三方收款服务商对比

服务商优势适合
PingPong亚马逊卖家最多、国内客服好亚马逊主战场
连连 LianLian生态全、多币种、供应链付款方便综合玩家
Airwallex 空中云汇独立站/Stripe 首选、支持虚拟卡品牌型卖家
万里汇 WorldFirst费率有优势、退税服务（蚂蚁旗下）电商生态强
Payoneer老牌、eBay 卖家用得多综合海外

财务基本要做到的 5 件事

1. 公私分离

所有平台放款、供应商付款都走对公。私户周转 = 定时炸弹。

2. 月度记账

用记账代理或云记账工具，产出资产负债表 + 利润表。

3. 单品利润表（最重要）

SKU 级别每月核算利润率。→ 用工具算

4. 现金流预算

至少 8 周现金流预测。跨境电商钱最容易死。

5. 税务合规

小规模季度申报 / 一般纳税人月度申报。

💡 新手第一原则

净利率 < 10% 的品慎做，除非有明确起量路径。

5. 图文素材与详情页

为什么图文比广告还重要：主图决定 CTR，视频/A+ 决定 CVR。同样的品，好主图能拉 3 倍点击。这是最高性价比的一次性投入。

必须准备的素材清单

📸 图片
  • 主图（白底）1000×1000 起，主体清晰
  • 场景图 / lifestyle：4–6 张
  • 卖点图 / infographic：3–5 张
  • 尺寸/参数图：1 张
  • 对比图：与竞品/旧款
  • 包装图：1 张
🎬 视频与富媒体
  • 主视频 15–30s（Listing / 广告用）
  • 详情演示 45–90s
  • UGC 素材 15–60s（广告最强杠杆）
  • A+ / EBC 图文模块（亚马逊）

→ 详见 Listing 专题

6. 流量与广告

流量三大来源

自然流量（SEO / 搜索排名）
付费流量（广告投放）
社交流量（内容 / 网红 / UGC）

新手节奏：付费拉新 → 沉淀评价与排名 → 撬动自然流量 → 逐步降低广告依赖。只做免费流量的独立站基本起不来。

4 个关键指标（背下来）

CTR 点击率
Amazon 0.3–0.6% · Meta 1–3%
CVR 转化率
Amazon 8–15% · 独立站 1–3%
ROAS
独立站需 > 2.5–3
ACoS（亚马逊）
目标 < 毛利率

新品期广告心法（前 30 天）

🎯 不要看盈利，看关键词收集 + 评价累积 + 排名爬升。
💰 预算控制在售价的 20–40%（TACoS 20–40%）。
🔄 每 3 天优化一次：砍高花费无转化词，加低花费高转化词。
🖼️ 主图 A/B 测试永远比调竞价重要。

广告投放 6 个常见坑

  1. 一上来就打大预算，钱烧完没数据
  2. 一直看 ROAS 不看归因（Meta / Google / GA 用多源交叉）
  3. 只投最贵关键词（长尾 CPC 便宜 3–5 倍）
  4. 不算 LTV，只算首单 ROAS
  5. 素材不换（3–5 天疲劳，每周产 5–10 条新素材）
  6. 不预留大促预算（黑五网一 CPC 是平时 2–4 倍）

7. 客服与售后

亚马逊 ODR > 1% 就会预警，账号有停号风险。Shopee/Lazada 有本地客服响应时限（12–24 小时未回复直接扣分）。

合规拿评价的方式 vs 严禁触碰的红线

✅ 合规通道
  • Amazon Vine（品牌备案，一次 30 单）
  • Amazon Request a Review 按钮
  • Shopee/Lazada 系统自动催评
  • 独立站 Judge.me / Loox / Yotpo 邮件催评
  • 老客户返视频活动（明示有偿）
❌ 严禁红线
  • 付费好评 / 送礼换好评
  • 亲友/员工用不同 IP 下单评价
  • Facebook / Telegram 评价群
  • 卡片直接引导"好评送礼"

8. 数据与复盘

必看的 5 张表

  1. 单品利润表：SKU × 月，每个 SKU 净利率一目了然
  2. 广告表：平台 × 广告系列 × ACoS/ROAS × 周
  3. 库存表：SKU × 仓库 × 现有 × 日均销量 × 剩余可售天数 × 补货建议
  4. 现金流表：8 周滚动预测
  5. 平台健康表：ODR、LSR、CR、政策违规、评分按周

周复盘模板（30 分钟）

① 上周 GMV / 净利 vs 目标           【数字】
② 广告 ACoS / ROAS 变化              【数字】
③ 新品测款进展                       【1–2 行】
④ 库存红黄绿灯                       【SKU 清单】
⑤ 平台账号健康                       【1 行】
⑥ 本周 3 个最重要的动作              【To-do】

❓ 2

❓ 3

❓ 4

决策原则（不知道下一步做什么时看这里）

  1. 有数据不吵架：所有决定用最近 14/28 天数据说话
  2. 一次只改一个变量：换主图 + 改标题 + 加视频一起动 = 无法归因
  3. 止损比冲刺重要：亏损 SKU 一个月内没起色，果断清仓
  4. 20% 品带来 80% 利润：注意力放头部 SKU，长尾能清就清
  5. 别自嗨"再等等就爆了"：设明确验证周期（14/28/60 天）到点做决定
