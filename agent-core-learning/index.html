ui:// 预制 HTML

搭配口径：A2UI + AG-UI（管道+内容）；A2UI + A2A（多 Agent 间传输）；A2UI + MCP（官方称即将有桥接）。想让服务端拥有完整 UI 体验用 MCP Apps，想要贴合自家 App、跨平台的动态 UI 用 A2UI。
